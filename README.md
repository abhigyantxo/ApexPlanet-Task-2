TaskFlow — Productivity Dashboard

A responsive web application for task management and contact form validation, developed as part of the ApexPlanet Web Development Internship.

Overview

TaskFlow is a front-end productivity application designed with a focus on usability, responsive layouts, and interactive functionality. It provides a structured interface for managing daily tasks and validating contact form submissions.

Key Features

* Responsive Interface: Adapts to different screen sizes using CSS Grid, Flexbox, and media queries.
* Form Validation: Validates required fields and email format using JavaScript.
* Task Management: Supports adding tasks, marking them as complete, and deleting them dynamically.
* User-Focused Design: Uses consistent typography, spacing, and a clean visual hierarchy.

Technology Stack

Technology	Implementation
HTML5	Semantic page structure
CSS3	Layout, styling, Flexbox, Grid, and responsive design
JavaScript	Client-side form validation and dynamic task management

Getting Started

Prerequisites

A modern web browser. No additional dependencies are required.

Run Locally

1. Clone or download this repository.
2. Open the project directory in Visual Studio Code.
3. Open index.html in a web browser.

Implementation Notes

* Form validation is performed on the client side.
* The contact form is a front-end demonstration and does not send messages to a backend.
* Tasks are managed dynamically in the current page session and are not persisted after a page refresh.
