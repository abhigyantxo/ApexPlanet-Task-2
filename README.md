# TaskFlow — Productivity Dashboard

A responsive front-end productivity application developed as part of the ApexPlanet Web Development Internship.

## Overview

TaskFlow is a modern productivity dashboard designed to help users organize daily tasks and interact with a validated contact form. The project demonstrates responsive design, usability, and core front-end development concepts.

## Features

- **Responsive Design:** Adapts to desktop and mobile screens using CSS Grid, Flexbox, and media queries.
- **Contact Form Validation:** Checks required fields and validates email addresses using JavaScript.
- **Dynamic Task Management:** Add tasks, mark them as complete, and delete them without reloading the page.
- **Clean User Interface:** Consistent typography, spacing, and a minimal visual design.

## Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, Flexbox, Grid, and responsive design |
| JavaScript | Form validation and task interactions |

## Getting Started

### Requirements

A modern web browser. No additional dependencies are required.

### Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## Implementation Notes

- Form validation runs on the client side.
- The contact form is a demonstration and does not send messages to a backend.
- Tasks are not saved after refreshing the page.
